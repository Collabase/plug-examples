# Math helper

Sum, average and round numbers. Shows list properties and input validation. No connection needed.

## Configuration

- Sum and Average: `values`, a list of numbers. Output: `{ count, sum }` or `{ average, min, max }`.
- Round: `value` and `decimals` (default 2).

## Build

```
collabase-plug build .
```

The package is written to `dist/`. Upload it with `collabase-plug publish`.
